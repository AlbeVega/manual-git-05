# Introducción a GitHub

**GitHub** es la plataforma de desarrollo colaborativo más popular del mundo, basada en la nube y utilizada para alojar, gestionar y compartir código fuente de proyectos de software. 

Fundada en 2008 y adquirida por Microsoft en 2018, GitHub actúa como una red social para programadores donde desarrolladores individuales, equipos y empresas colaboran en proyectos de cualquier tamaño.

---

## 🔑 Conceptos Clave

* **Git:** Sistema de control de versiones distribuido que funciona en segundo plano. Permite registrar cambios en los archivos a lo largo del tiempo, volver a versiones anteriores y trabajar en distintas ramas de código en paralelo.
* **Repositorio (Repo):** Espacio centralizado donde se almacenan todos los archivos de un proyecto, junto con el historial completo de sus revisiones.
* **Commit:** Captura del estado del código en un momento determinado. Funciona como un punto de guardado etiquetado con un mensaje explicativo.
* **Rama (Branch):** Copia independiente del proyecto principal para desarrollar nuevas funciones o corregir errores sin alterar el código estable. La rama principal se denomina habitualmente `main`.
* **Pull Request (PR):** Solicitud para fusionar los cambios realizados en una rama secundaria dentro de la rama principal. Facilita la revisión de código y la discusión en equipo antes de integrar los cambios.
* **Fork:** Copia exacta del repositorio de otro usuario en tu propia cuenta de GitHub para realizar modificaciones de manera independiente sin afectar el proyecto original.

---
## 🚀 Principales Usos y Beneficios

* **Control de versiones en la nube:** Accede y respalda tu código desde cualquier lugar de manera segura.
* **Colaboración eficiente:** Permite a múltiples desarrolladores trabajar simultáneamente en el mismo proyecto sin sobreescribir el trabajo de otros.
* **Gestión de proyectos:** Incluye herramientas integradas como *Issues* (seguimiento de tareas y errores) y *Projects* (tableros organizativos estilo Kanban).
* **Portafolio profesional:** Funciona como una carta de presentación interactiva para mostrar proyectos personales y contribuciones a empleadores o a la comunidad.
* **Automatización y CI/CD:** Mediante *GitHub Actions*, permite ejecutar pruebas unitarias y desplegar código de forma automática.
